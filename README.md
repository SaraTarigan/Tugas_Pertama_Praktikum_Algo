Cocoa Heaven Management System
Cocoa Heaven Management System adalah aplikasi berbasis C++ (console) yang digunakan untuk mengelola data karyawan dan data barang pada toko Cocoa Heaven.
Program ini menggunakan file handling untuk menyimpan data serta menerapkan algoritma sorting dan searching.
Fitur Utama
1. Admin memiliki akses untuk mengelola data karyawan:
   Login admin, menambah data karyawan, melihat data karyawan, mencari data karyawan (ID / Nama), mengurutkan data karyawan dan logout
2. Karyawan dapat mengelola data barang toko:
   Menambah data barang, melihat data barang, mengedit data barang, mencari data barang dan logout
3. Program ini mengimplementasikan beberapa algoritma dasar struktur data:
   Sorting : Bubble Sort (Ascending) dan Quick Sort (Descending)
   Searching : Sequential Search dan Binary Search
4. Data disimpan menggunakan file eksternal
File karyawan.txt	untuk menyimpan data karyawan dan file barang.txt untuk menyimpan data barang
